# Services and Third-Party Integrations

This document describes the application service layer contracts, external library integrations (ClosedXML, CsvHelper), and audit logging mechanisms.

---

## 1. Application Service Contracts

All business use cases are encapsulated within interfaces located in `Solution.Application.Interfaces`:

| Interface | Implementation | Responsibility |
| :--- | :--- | :--- |
| **`IMemberService`** | `MemberService` | Member profile queries, search filtering, manual creation, updates, and photo retrieval. |
| **`IImportService`** | `ImportService` | Ingests Excel and CSV spreadsheets, validates data integrity, checks duplicates, and performs bulk database inserts. |
| **`IReunionService`** | `ReunionService` | Manages reunion events, itineraries, registrations, transit arrangements, and accommodation needs. |
| **`IPaymentService`** | `PaymentService` | Processes veteran payment submissions, duplicate reference checking, receipt streaming, and administrative verification/rejection. |
| **`IDashboardService`** | `DashboardService` | Computes statistical metrics for both the Organizer Dashboard and the Veteran Portal. |
| **`IReportService`** | `ReportService` | Generates 14 distinct Excel workbooks (via ClosedXML) and CSV streams (via CsvHelper). |
| **`IAuditLogger`** | `AuditLogger` | Records critical actions (logins, imports, verifications, rejections, edits) for accountability. |

## 2. Dependency Injection Registration

All application services and DbContexts are registered in [ServiceCollectionExtensions.cs](file:///e:/ProjectTemplate/src/Solution.Web/Extensions/ServiceCollectionExtensions.cs):

```csharp
public static IServiceCollection AddApplicationServices(this IServiceCollection services, IConfiguration configuration)
{
    // Persistence
    services.AddDbContext<AppDbContext>(options =>
        options.UseSqlServer(configuration.GetConnectionString("DefaultConnection")));
    services.AddDbContext<AppIdentityDbContext>(options =>
        options.UseSqlServer(configuration.GetConnectionString("DefaultConnection")));

    // Domain / Application Services (Scoped to HTTP Request)
    services.AddScoped<IMemberService, MemberService>();
    services.AddScoped<IImportService, ImportService>();
    services.AddScoped<IReunionService, ReunionService>();
    services.AddScoped<IPaymentService, PaymentService>();
    services.AddScoped<IDashboardService, DashboardService>();
    services.AddScoped<IReportService, ReportService>();
    services.AddScoped<IAuditLogger, AuditLogger>();

    return services;
}
```

## 3. Spreadsheet Integration: ClosedXML

The application uses **ClosedXML** (`v0.105.1`) for generating professional Excel workbooks and parsing uploaded sheets.

### Crucial Implementation Rule: 31-Character Sheet Name Limit
OpenXML and Excel strictly prohibit worksheet names longer than 31 characters. Exceeding this limit throws an unhandled exception:
```csharp
// Correct pattern: Sanitize and truncate sheet names
string safeSheetName = reportTitle.Length > 31 
    ? reportTitle.Substring(0, 31) 
    : reportTitle;
var worksheet = workbook.Worksheets.Add(safeSheetName);
```

### Styling Standards for Generated Workbooks:
- **Header Row**: Fill color dark navy `#0B2545`, font white bold, centered.
- **Data Rows**: Left-aligned text, right-aligned currency/numbers, centered dates (`yyyy-MM-dd`).
- **Autofit**: `worksheet.Columns().AdjustToContents()` called before saving to memory stream.

## 4. CSV Streaming Integration: CsvHelper

For high-throughput lightweight exports and imports, the application utilizes **CsvHelper** (`v33.1.0`):

```csharp
public async Task<byte[]> GenerateCsvReportAsync<T>(IEnumerable<T> records)
{
    using var memoryStream = new MemoryStream();
    using (var writer = new StreamWriter(memoryStream, Encoding.UTF8))
    using (var csv = new CsvWriter(writer, CultureInfo.InvariantCulture))
    {
        await csv.WriteRecordsAsync(records).ConfigureAwait(false);
    }
    return memoryStream.ToArray();
}
```

### Key Practices:
- Always specify `CultureInfo.InvariantCulture` to prevent decimal comma formatting issues in localized systems.
- Use asynchronous streaming (`WriteRecordsAsync`) when handling large datasets.

## 5. Audit Logging Architecture: `IAuditLogger`

Security-sensitive and operational actions are logged to maintain an immutable audit trail:

```csharp
public interface IAuditLogger
{
    Task LogAsync(string action, string entityName, string entityKey, string performedBy, string details);
}
```

### Tracked Events:
- Member data bulk import (timestamp, file name, rows processed, rows rejected).
- Member account provisioning (target ServiceNo, generated by, timestamp).
- Member account activation (ServiceNo, IP address, timestamp).
- Payment verification or rejection (PaymentId, reviewer, status change, rejection reason).
- Member record modification (ServiceNo, modified fields, editor identity).
